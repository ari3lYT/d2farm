# D2Farm

[English](README.md) · **Русский**

D2Farm — серверное расширение фермерства для Fabric, целиком построенное на ванильных блоках и предметах. Игрокам не нужен клиентский мод или ресурс-пак.

## Возможности

| Инструмент | Действие |
| --- | --- |
| Мотыга сеятеля | Вспахивает и засеивает область 3×3 семенами из второй руки |
| Мотыга жнеца | Собирает зрелые культуры в области 3×3 и пересаживает их из реально выпавших предметов |
| Садовая мотыга | Собирает и пересаживает одну культуру; не даёт владельцу вытоптать свою грядку |
| Компост | Добавляет грядке пять зарядов усиленного урожая |

Использование с Shift ограничивает площадные инструменты одним блоком. Поддерживаются пшеница, морковь, картофель и свёкла.

Подготовленная грядка под открытым небом во время дождя получает бонус 50% к шансу естественного роста. Ванильные правила света, увлажнения и роста продолжают действовать; стадии не пропускаются, костная мука не меняется, обычные грядки не затрагиваются.

## Устройство и безопасность

- Повторная посадка расходует семена из реального урожая и не создаёт бесплатные материалы.
- Прочность тратится за каждый затронутый блок; операция останавливается, когда инструмент ломается.
- Чары, пользовательские имена и повреждение сохраняются при улучшении по рецепту.
- Для каждого блока проверяются дальность, прямая видимость, защита спавна и Fabric-события использования/разрушения.
- Плодородие хранится в `PersistentState` мира; сканирования мира и фоновых задач на каждое растение нет.
- Необязательная интеграция с Ledger обнаруживается через reflection. Если установленный Ledger API не может записать изменение, D2Farm безопасно блокирует дополнительное действие.

Сейчас мод работает только в обычном мире (Overworld).

## Совместимость

- Minecraft `1.21.11`
- Fabric Loader `0.18.4+`
- Fabric API
- Java 21

## Сборка и тесты

```bash
JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64 ./gradlew test build
```

Изолированный игровой тест клиента запускается так:

```bash
JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64 \
LIBGL_ALWAYS_SOFTWARE=1 ALSOFT_DRIVERS=null \
xvfb-run -a -s '-screen 0 1280x720x24 -nolisten tcp' \
./gradlew runClientGameTest
```

Готовый JAR появляется в `build/libs/`.

## Установка

1. Создайте резервную копию мира.
2. Установите на сервер Fabric Loader и Fabric API.
3. Поместите JAR D2Farm в `mods/`.
4. Обычным образом перезапустите сервер.

После удаления мода преобразование блоков не требуется: в мире используются только ванильные блоки и предметы. Метаданные плодородия просто перестанут использоваться.
